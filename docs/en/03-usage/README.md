# Using vAi

The following are needed to build and run a neural network with vAi.

| | |
|---|---|
| [Node](node.md) | A single operation. It sends and receives tensors through slots |
| [NodeGroup](node-group.md) | A subgraph that groups multiple nodes as one |
| [NeuralNet](neural-net.md) | The entire graph. It manages execution and buffers |
| [Tensor](tensor.md) | Data that flows between nodes |
| [Execution pipeline](execution-pipeline.md) | What happens in one call to `model(...)` |
| [Profiling](profiling.md) | Per-section timing |
